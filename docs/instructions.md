# 総合インストラクションの例（貼り付け用）

`/ced-skills:explain` を使うときの、そのまま貼れる指示の例です。URL かファイルのパスを入れて使ってください。

## 1. コマンドで実行する（引数で答えを渡す。質問は出ない）

```
/ced-skills:explain <URL または ファイルのパス> --out ./explain-out --slides 8 --audience 実務で使う人
```

## 2. 対話で実行する（足りない答えだけ、1 回にまとめて聞かれる）

```
/ced-skills:explain <URL または ファイルのパス>
```

聞かれる項目（足りないものだけ。最大 3 問）:
- 出力先（既定: `./explain-out`）
- スライドの枚数（既定: 6 枚）
- 読み手（既定: 初めて読む人）

## 3. 自然文で頼む（スキルを直接使う場合）

```
次の資料から、解説メモと解説スライド（MD と HTML）を作ってください。
資料: <URL または ファイルのパス>
出力先: ./explain-out
スライドは 8 枚、読み手は実務で使う人です。
```

## 注意

- YouTube の字幕が取れないときは、その理由が報告されます。別の動画に差し替える場合は、新しい URL で再実行してください。
- スライドの HTML を作る前に、スライド MD の lint（error と warn）が 0 になるまで直されます。
- 同じ出力先に再実行すると、既存のファイルは上書きされます。残したいものは別のフォルダに移してください。

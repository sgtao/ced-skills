# プロファイル：document（PDF・Office 資料。`source_format: pdf`・`docx`・`pptx`・`xlsx`）

| 項目 | 決まり |
|---|---|
| 入力の形 | PDF 経由（`conversion: pdf`）は章・節の見出しと表・SVG の図（ページ番号の区切りが無いこともある）。直接変換（`conversion: direct`）の pptx は `<!-- Slide number: N -->` ごとの区切りと、末尾の「補足」節 |
| セクションの取り方 | 目次 → 章の見出し → ページ／スライド番号のまとまり。`scaffold.py` が返す見出しを使う。**最初の `# `（資料の題名。pptx では表紙のスライド）はセクションにならない**（セクション番号はスライド番号と一致しない。表紙の内容は README の概要・`01_source.md` の要約・解説の冒頭で扱う）。`### Notes:`・`### Chart` などの小見出しはセクションにしない |
| 目次の書き方 | `- N : [章の見出し](#アンカー)`（`scaffold.py` の行をそのまま使う。見出しの番号 `1.` が名前に残ってよい）。見出しが無い資料は `- N : 名前 ｜ p.3〜5`（ページ・スライドの範囲） |
| 本文の扱い | **複製して変えない**。「再現できなかったもの」「補足」の節もそのまま残る |
| 根拠の示し方 | ページ・スライド番号があるとき `第2章 p.5「…」`／`スライド3「…」`。**番号が無い資料**（見出しだけで区切られた PDF 経由）は `「<見出し>」の節「…」`。pptx の末尾「補足」の節は `補足の節「…」`。本文と補足に同じ表が重なっているときは、**本文側**を根拠にする |
| 02 の `<範囲>` | `p.3〜5`・`スライド3`。番号が無いときは `見出しの節`（`references/output-formats.md` の 3） |
| 図・表・コード | **再現されている**表・SVG・Mermaid は根拠に使ってよい（SVG はテキストの文字をそのまま引用する：`図1「4月 100」`）。**`conversion` が `direct` か `model-read` のとき、または「再現できなかったもの」の節があるときは、図に基づく記述を避け**、その旨を README の概要の末尾と解説の注意に書く。避けるのは、図形・画像の**内容を読み取って書くこと**。置かれている画像のファイル名（`flow.png` など）や、図があるという事実に触れるのはよい。図形に添えられたテキストから手順の順序などを読むときは `【推測】` を付ける |
| 気を付ける点 | スライドは文が短く、行間を補いたくなる。**補ったら `【補足】`**。表紙・副題のチーム名などから、聞き手か発表者かを決めない（本文に書いていない）。発表者ノート・非表示スライドは本文に含まれているかを確かめる。`has_figures: true` でも、図が再現されているとは限らない。frontmatter の `summary` が要約になっていない（著者名だけなど）ことがある。その場合は本文から要約を書く |

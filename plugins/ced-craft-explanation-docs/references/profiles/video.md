# プロファイル：video（動画の字幕。`source_format: youtube`）

| 項目 | 決まり |
|---|---|
| 入力の形 | `# タイトル` → `## 概要`（概要欄の全文）→ `## Transcript`（段落頭に `**[MM:SS]**`）。句読点がほとんど無い。自動字幕なら聞き取り違いがある |
| セクションの取り方 | ① 概要欄のチャプター（`scaffold.py` が `sections.chapters` で返す。そのまま使う）→ ② 無ければ**スキルが区切る**。話題の切れ目で、順序は変えず、4〜10 個を目安に |
| 目次の書き方 | `- N : 名前 ｜ MM:SS〜MM:SS`。スキルが区切ったときは `- N : 名前 ｜ スキルが区切った・MM:SS〜MM:SS・「書き出し 20 字」`。README には「スキルが区切ったセクションです」の 1 行を添える |
| 本文の扱い | **複製して変えない**。清書（句読点の補完・誤変換の訂正）はしない。誤変換らしい箇所は、解説の中で `【推測】` を付けて扱う（例：「在庫回転立」は「在庫回転率」の聞き取り違いと思われる【推測】） |
| 根拠の示し方 | `セクション2 在庫回転率とは [03:15]「…」`（セクション名＋`[MM:SS]`＋引用）。引用は、その段落の字幕から一字一句同じに切り出す。段落をまたがない |
| 図・表・コード | ほぼ無い |
| 気を付ける点 | 話し言葉の言い間違い・聞き取り違い。数字・固有名詞は特に疑う。推測で直したら「推測」と書く。概要欄にリンクや宣伝があっても消さない |
| 概要欄のチャプターが無いとき | 字幕の `**[MM:SS]**` の範囲でセクションを区切る。区切りの基準を `out/00_run-report.md` に 1 行書く |
